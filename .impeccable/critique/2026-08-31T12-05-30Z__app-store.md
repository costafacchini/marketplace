## Priority Issues

P0 — Wrong brand name: store.name = "Small Business Seller" in messages/pt.json. Fix: change to "Sonho de Mulher".

P0 — Cart cleared before WhatsApp confirmed: ConfirmModal.tsx calls clear() unconditionally after window.open(). Blocked popup → order destroyed. Fix: check window.open return value; snapshot cart to localStorage before clearing.

P1 — WhatsApp model invisible until commit: no mention of WhatsApp before ConfirmModal fires. Fix: one-line explainer in CartSummary; message preview in ConfirmModal.

P1 — CartItemRow "Quantidade: M": qty label applied to size value. Fix: add "tamanho" key to locale files; separate size/quantity display; replace readOnly number input with span.

P2 — Sort control above fold: header + tabs + sort = ~140px before first product on 375px phone. Fix: collapse SortControl to icon button on mobile.
